# Release Issue: Bundle Installers Missed by the Bump Script

- **Previous version:** 6.48.0
- **New version:** 6.49.0
- **Step flagged:** version bump (`python 03-ai-scripts/37-bump-version.py --version 6.49.0`)
- **Finding:** the 14 bundle installers (`cli-`, `consolidated-`, `error-manage-`, `linters-`, `slides-`, `splitdb-`, and `wp-install` in `.sh` and `.ps1`) still printed and documented v6.46.0. The bump script updates `version.json`, `package.json`, `prompt-version.template.json`, `readme.md`, and the changelogs, and runs `npm run sync`, but none of these regenerate the installers. The pre-release gate regenerates them, but it runs before the bump, so they would have been pinned one version behind.
- **Resolution:** on the release branch, after the bump, `node scripts/generate-bundle-installers.mjs` regenerated all 14 files at v6.49.0 (21 pin lines), and they are part of the release commit.
- **Follow-up (unresolved):** make `03-ai-scripts/37-bump-version.py` or `scripts/bump-version.mjs` run `scripts/generate-bundle-installers.mjs` after the sync, so future releases do not depend on this manual step.
