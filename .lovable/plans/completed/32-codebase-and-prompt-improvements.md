## 2. Task-Specific Rules & Constraints

1. **WOR Policy (Strict):** Under NO circumstances should `package.json` be bumped or git tags generated. All commits remain standard development commits.
2. **Function Body Cap:** Every function in Go or Python MUST be $\le 15$ lines (prefer $\le 8$).
3. **Strict Relative Git Paths:** Zero absolute filesystem paths (`C:\...`, `/home/...`) and zero `file:///` URIs inside any repository files or documentation.
4. **Boolean Conventions:** Implicit booleans only (`if is_valid:` / `if isValid { ... }`), no explicit `== true`/`== false`, no mixed polarity, positive `is`/`has` prefixes only.
5. **Quality Gates Integrity:** 100% of all Go unit tests must pass, and all CI/CD quality gates in `03-ai-scripts/06-cicd-local-runner.py` must pass.
