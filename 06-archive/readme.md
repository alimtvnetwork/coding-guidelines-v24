# Archived Prompt Tiers (`execute`, `v1`, `v2`, `v3`, `v4`)

This directory stores historical versioned prompt tiers (`execute/`, `v1/`, `v2/`, `v3/`, and `v4/`) for archival reference inside the `coding-guidelines` repository.

- **Archived Categories:**
  - `execute/`: Archived legacy execute prompt versions (`v2`, `v3`, `v4`, `v5`, and legacy `excute-parent-old.md`).
  - `v1/`: Legacy V1 prompt tier.
  - `v2/`: Legacy V2 prompt tier.
  - `v3/`: Legacy V3 prompt tier.
  - `v4/`: Legacy V4 prompt tier.
- **Active Prompts:** The active, canonical V6 prompts live directly in [`01-prompts/`](01-prompts/) (including canonical V6 execute prompts in `01-prompts/14-execute/`).
- **Sync Exclusion Policy:** `06-archive/` is **NEVER** synchronized to downstream repositories. Only [`01-prompts/`](01-prompts/) is synchronized across connected repositories.
